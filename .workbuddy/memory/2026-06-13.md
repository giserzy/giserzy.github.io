# 2026-06-13

## 双语网站建设

为 Jekyll 学术主页（giserzhang.xyz）新增完整中文版，实现中英双语一键切换。

### 新增文件

- `_pages/about-zh.md` — 中文首页，permalink: /zh/
- `_pages/cv-zh.md` — 中文简历，permalink: /zh/cv/
- `_pages/publications-zh.html` — 中文论文页，permalink: /zh/publications/
- `_pages/portfolio-zh.html` — 中文项目页，permalink: /zh/portfolio/
- `_pages/year-archive-zh.html` — 中文动态页，permalink: /zh/year-archive/
- `_pages/markdown-zh.md` — 中文GISChat学人页，permalink: /zh/markdown/
- `_data/navigation-zh.yml` — 中文导航菜单数据

### 修改文件

- `_includes/masthead.html` — 新增：
  1. 语言感知导航（page.lang == 'zh' 时加载中文菜单）
  2. 右上角固定悬浮语言切换按钮（English / 中文）
  3. 智能路由映射：根据当前 URL 自动跳转对应语言版本

### 技术方案

- 利用 Jekyll front matter `lang: zh` 标记中文页面
- 语言切换按钮通过纯 JS 实现，基于 routeMap 对象做页面对应关系映射
- 中文页面统一在 /zh/ 路径下，结构与英文版完全镜像
- 无需插件，兼容 GitHub Pages 静态部署
